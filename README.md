# Tower Stack

A 2D tower-stacking game made with Unity. Tap to drop the moving block; the part that hangs over the tower is cut off and falls. Land it almost exactly on top for a **Perfect** and build combos.

## Features
- Block slicing with falling off-cut pieces (Rigidbody2D physics)
- Perfect placement detection, combo counter and tiered combo effects
- Elemental blocks (fire, ice, wind, electric) with their own colours and effects
- Camera that follows the tower, camera shake, score punch animation
- Intro fade, start / game over panels, saved high score

## Open the project
1. Install **Unity 6.3 LTS** with **Android Build Support** from Unity Hub.
2. Clone this repository.
3. Unity Hub → Projects → Add → Add project from disk → select the repository folder (the one that contains `Assets` and `ProjectSettings`).
4. Open `Assets/Scenes/SampleScene.unity`.
